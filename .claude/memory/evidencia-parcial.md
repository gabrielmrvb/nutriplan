Toda afirmação sobre o estado do sistema leva a classe da evidência
(`[EXECUTADA]`, `[OBSERVADA]`, `[LIDA NO CÓDIGO]`…, ver CLAUDE.md) e o
lugar: navegador em produção, HTTP em produção e teste local são coisas
diferentes, e teste ou ambiente controlado NUNCA é "produção real" — foi
correção explícita do dono. Generalizações que já enganaram aqui: GET mostra
o campo ≠ POST persiste; model registrado ≠ pessoa acessa; input fora do
HTML ≠ dado invisível; banco local ≠ Neon; lista parcial ≠ inventário;
código certo ≠ configuração persistida; função testada ≠ integração com o
deploy.
