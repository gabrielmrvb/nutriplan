Sobre esta demonstração

Este é um ambiente de demonstração do NutriPlan. Todos os dados apresentados são fictícios. Nenhuma informação real de usuário do sistema está sendo exibida aqui.

O que você está vendo

As telas são as mesmas do aplicativo — o mesmo código, os mesmos cálculos, o mesmo desenho. O que muda é de quem são os dados: tudo roda sobre Carlos Silva, um personagem inventado para esta demonstração, com 28 anos, 78 kg, 1,78 m e objetivo de hipertrofia.

A meta calórica, os macros, o cardápio e a ficha de treino dele não foram escritos à mão: saíram do mesmo motor que atende qualquer pessoa no app. É por isso que o demo continua parecido com o produto quando o produto muda.

O que não funciona aqui

Nada que escreva. Marcar refeição, registrar carga, anotar água, salvar perfil — tudo isso é recusado antes de chegar ao servidor, e você recebe um aviso explicando. É a única garantia que não depende de eu ter lembrado de proteger cada botão: o modo demo simplesmente não aceita método que altere dado.

Login, cadastro e recuperação de senha também ficam de fora: o demo não tem conta para entrar.

Como os dados reais ficam protegidos

  • O usuário do demo é uma conta separada, com senha inutilizável.
  • Toda requisição de escrita é recusada no middleware, antes da view.
  • O demo não tem acesso a nenhum outro usuário: as telas leem sempre o usuário da requisição, e no demo ele é sempre o Carlos.
